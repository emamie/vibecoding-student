# جلسهٔ ۲ — وایب‌کدینگ و اولین ابزار

## درسِ ۲.۱ — وایب‌کدینگ چیست؟

_(این درس پرامپتی ندارد.)_

## درسِ ۲.۲ — اولین ابزار: چک‌لیست‌ساز

**به Claude:**

```text
یک صفحهٔ وب تک‌فایلی به اسم index.html بساز: یک چک‌لیست ساده که بتوانم مورد اضافه کنم، تیکش بزنم و حذفش کنم. فارسی و راست‌چین باشد، ظاهرش تمیز باشد، و اگر صفحه را بستم و دوباره باز کردم موردها سر جایشان بمانند.
```

## درسِ ۲.۳ — بهتر کردن با درخواست‌های کوچک

**به Claude:**

```text
بالای چک‌لیست، تاریخ امروز را به شمسی نشان بده.
```

**به Claude:**

```text
یک دکمه اضافه کن که همهٔ موردهای تیک‌خورده را یک‌جا پاک کند.
```

## درسِ ۲.۴ — نقطهٔ ذخیره و برگشتن از اشتباه

**به Claude:**

```text
از وضعیت فعلی پروژه یک نقطهٔ ذخیره با git بساز. اگر git هنوز راه‌اندازی نشده، راه‌اندازی‌اش کن. توضیحت را خیلی ساده و کوتاه بنویس.
```

**به Claude:**

```text
پس‌زمینهٔ صفحه را قرمز تند کن.
```

**به Claude:**

```text
این آخرین تغییر را برگردان؛ پروژه را به همان نقطهٔ ذخیره برگردان.
```
