# جلسهٔ ۷ — پروژه‌ها

پروژهٔ آمادهٔ شروعِ این جلسه: [`starters/session-07/`](../starters/session-07/)

## درسِ ۷.۱ — پروژه‌ها و رابطه با کارها

**به Claude:**

```text
می‌خواهم «پروژه‌ها» اضافه شوند و هر کار بتواند به یک پروژه تعلق داشته باشد. فقط طرح بده: جدول پروژه چه فیلدهایی دارد و رابطه‌اش با کارها چطور است. ساده و فارسی.
```

**به Claude:**

```text
اگر پروژه‌ای حذف شد، کارهایش بمانند ولی بدون پروژه. حالا بساز.
```

## درسِ ۷.۲ — صفحهٔ پروژه‌ها

**به Claude:**

```text
صفحهٔ «پروژه‌ها» را بساز: فهرست پروژه‌ها با تعداد کارهای هرکدام، افزودن پروژه، و با کلیک روی هر پروژه، کارهایش. در فرم کار هم بتوانم پروژه را انتخاب کنم.
```

**به Claude (فقط اگر اول طرح داد و منتظرِ تأیید ماند):**

```text
خوب است، بساز.
```

## درسِ ۷.۳ — یک جزء، چند جا

**به Claude:**

```text
کارت کارها و کارت پروژه‌ها شبیه هم‌اند. یک جزء مشترک برایشان بساز تا ظاهرشان از یک جا کنترل شود. ظاهر صفحه نباید عوض شود. اول نقطهٔ ذخیره بساز.
```

**به Claude (فقط اگر اول طرح داد و منتظرِ تأیید ماند):**

```text
خوب است، بساز.
```
