# وایب‌کدینگ با Claude: فایل‌های دوره

همهٔ پرامپت‌ها و فایل‌هایی که در ویدیوهای دوره به کار می‌روند، این‌جاست.

## دانلود

۱. بالای صفحهٔ اصلیِ همین مخزن، روی دکمهٔ سبزِ **Code** کلیک کنید و **Download ZIP** را بزنید.
۲. روی فایلِ دانلودشده راست‌کلیک کنید و **Extract All** را بزنید.

هر وقت فایل‌های جلسه‌های تازه اضافه شد، دوباره همین‌طور دانلود کنید.

## پرامپت‌ها

در پوشهٔ [`prompts`](prompts/)، هر جلسه یک فایل دارد. هر پرامپت یا دستور توی یک کادر است، و گوشهٔ هر
کادر یک دکمهٔ کپی هست. کپی کنید و توی پنلِ Claude یا ترمینال بچسبانید.

بعضی کادرها نوشته‌اند «فقط اگر اول طرح داد». Claude گاهی اول طرحِ کار را می‌گوید و منتظرِ تأیید می‌ماند،
و گاهی مستقیم می‌سازد. آن پیام را فقط وقتی بفرستید که منتظر مانده باشد.

جوابِ Claude برای شما ممکن است کمی با ویدیو فرق کند. اشکالی ندارد؛ مهم این است که نتیجه کار کند.

## پروژهٔ آمادهٔ هر جلسه

اگر از ویدیوها جا ماندید، یا پروژه‌تان خراب شد و برنمی‌گردد، از پوشهٔ [`starters`](starters/) پروژهٔ
آمادهٔ شروعِ همان جلسه را بردارید. هر کدام دقیقاً همان پروژه‌ای است که ویدیوی اولِ آن جلسه با آن شروع
می‌شود.

۱. پوشهٔ `my-desk` را از `starters/session-شمارهٔ جلسه` به جایی مثلِ **Documents** کپی کنید. اگر پروژهٔ
   خودتان هم آن‌جاست، اسمِ تازه‌ای به این یکی بدهید تا روی هم نیفتند.
۲. در VS Code، از منوی **File** گزینهٔ **Open Folder** را بزنید و همان پوشه را انتخاب کنید. اگر پرسید
   به سازنده‌های این پوشه اعتماد دارید، **Yes, I trust the authors** را بزنید.
۳. از منوی **Terminal** گزینهٔ **New Terminal** را بزنید و این دستور را بنویسید. فقط بارِ اول لازم است
   و چند دقیقه طول می‌کشد:

   ```text
   npm install
   ```

۴. بعد اپ را روشن کنید و در مرورگر `localhost:3000` را باز کنید:

   ```text
   npm run dev
   ```

اگر `npm install` با خطای `403` یا `ETIMEDOUT` ایستاد، مشکل از تحریم یا اینترنت است، نه از شما.
