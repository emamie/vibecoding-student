## درسِ ۱.۵ — نصب Git و Node.js

**در نوارِ آدرسِ مرورگر:**

```text
git-scm.com/install/windows
```

**در نوارِ آدرسِ مرورگر:**

```text
nodejs.org/en/download
```

**در ترمینال:**

```text
git --version
```

**در ترمینال:**

```text
node -v
```

**در ترمینال:**

```text
npm -v
```

**در ترمینال:**

```text
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
