# قانون‌های فنی پروژه (قالب دوره)

- ابزارها: Next.js (App Router) و TypeScript، Tailwind، Prisma با SQLite، Better Auth، کتابخانهٔ `openai` برای هوش مصنوعی، `date-fns-jalali` برای تاریخ شمسی.
- **فقط از کتابخانه‌هایی استفاده کن که در package.json نصب شده‌اند. چیز تازه‌ای نصب نکن**؛ اگر واقعاً لازم بود، اول بپرس.
- جزءهای رابط کاربری را خودت بنویس (با Tailwind و Radix که نصب شده‌اند)؛ فرمان `npx shadcn` را اجرا نکن.
- رابط فارسی و راست‌چین است: در Tailwind از کلاس‌های منطقی (`ms-*`، `me-*`، `ps-*`، `pe-*`، `start-*`، `end-*`) استفاده کن، نه `ml-*` و `mr-*`.
- همهٔ تاریخ‌هایی که کاربر می‌بیند شمسی‌اند.
- هوش مصنوعی فقط سمت سرور، با سه تنظیم `.env`: `AI_BASE_URL`، `AI_API_KEY`، `AI_MODEL`. کلید هرگز در کد سمت کاربر نیاید.
- اپ با `npm run dev` روی `localhost:3000` اجرا می‌شود و **معمولاً همین حالا روشن است: خودت دوباره اجرایش نکن** (دو سرور هم‌زمان پوشهٔ `.next` را خراب می‌کنند). برای امتحان، به همان `localhost:3000` درخواست بفرست، یا `npm run build` را نزن مگر از تو خواسته شود.
